Detailed Description

Serial logging that compiles away without DEBUG.

With DEBUG defined (the nodemcuv2_DEBUG env), the macros print to Serial. Without it, they expand to nothing, so their arguments are not evaluated.

void initDebugging ( )

Starts the serial port for the DEBUG_PRINT macros.

With DEBUG defined, opens Serial at MONITOR_SPEED baud and logs that debugging is initialized. Without it, does nothing. Call it once at the start of setup().
